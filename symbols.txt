# The analysis (tools/disassemble.py) starts at the vectors (RESET 6000, IRQ 65C4); these lines name what it

# ======== the vectors ========
6000  func  reset            # ORCC #$50, sprite RAM filled with F8, 100 frames waited (SYNC), DP = 0, the layers
                             # cleared, bank 3, then JMP $553A with the return address in Y (607D)
65C4  func  irq              # the VBLANK: the sprite DMA (STB $3C00) first, the frame counter (<$20), the
                             # frame's jobs, then the game state's routine in bank 3; the bank put back from <$D9

660D  data  irq_round_robin_banks             # 4 bytes: the bank of each job

                                                      # there (JMP $1A00): it switches banks, which the window
                                                      # cannot do under itself

617F  code  main_loop              # the task queue at <$12: each word's high bit clear is a task (its number in
                                   # A: JSR through the table at 6188, in bank 3); 6160 clears it
6188  data  main_tasks             # (the words read by LDX A,X at 6174)
